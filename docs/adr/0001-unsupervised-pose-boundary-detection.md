# ADR-0001: 无监督姿态边界检测，而非有监督动作识别

日期: 2026-11-06
状态: 已接受

## 背景

核心需求：对本地跟练视频（健身/瑜伽/HIIT）自动切分动作场景，提取每个场景的起始帧，点击缩略图跳转到该场景。素材是任意外部视频（如 B 站下载的跟练课），没有预定义动作类别表，也没有标注数据。

研究报告（`D:/vscode-project/reports/deep-research-report.md`）推荐的主线是 RTMPose + MS-TCN++/ASFormer 的有监督 Temporal Action Segmentation 路线。

## 决策

采用**无监督运动变化点检测**：基于姿态序列特征（关节速度/角度的变化）检测"运动模式发生明显变化"的时刻作为动作段边界。不识别动作语义名称，段名以"动作 N"占位。

## 理由

- 用户的核心诉求是"点一帧进入那个场景"，不需要知道动作叫什么。
- 有监督路线需要预定义类别 + 逐帧标注训练数据，对"任意本地视频"不成立。
- 无监督方案零训练、对任意素材通用，且边界检测精度对 ±1~2 秒的验收容忍度足够。

## 后果

- 放弃了动作标签能力。未来若需要"深蹲/平板支撑"等命名，需引入零样本动作识别或在无监督切分结果上做增量标注，两者都可以叠加在本方案之上，不推翻切分层。
- 边界检测质量依赖特征工程与阈值调节，需要提供可调参数（最短段长等）并靠人工验收迭代。
