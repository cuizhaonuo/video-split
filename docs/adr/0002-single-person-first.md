# ADR-0002: v1 按单人分析，多人跟踪延后

日期: 2026-11-06
状态: 已接受

## 背景

跟练视频画面中通常至少两人（教练 + 跟练者），且动作基本同步。姿态估计模型（YOLO11-pose）天然输出多人，但多人跟踪会引入人物 ID 漂移（遮挡后身份互换）问题。

## 决策

v1 采用**单人策略**：每帧取一个最显著的人物（bbox 最大/最居中，通常是教练），只分析这一条姿态轨迹。多人特征融合与完整跟踪延后。

## 理由

- 动作同步的前提下，一个人足以代表全场的运动模式。
- 单人选择逻辑简单、无 ID 漂移负担；主角短暂被遮挡时按位置+体型重新匹配即可。

## 后果

- 若未来素材出现"多人做不同动作"（如双人瑜伽），v1 输出不可用，届时需升级为多人跟踪 + 按人分段。
- 选人逻辑在镜头切换后可能短暂选错人，验收时需关注。
